### Objective
Build a reusable Python pipeline to clean sales data and generate business insights.

### Technologies
- Python
- Pandas
- NumPy
- Google Colab

### Tasks Completed

- Missing value handling

- Data type conversion
- Revenue calculation

- Product performance analysis
- Data quality reporting

- Average revenue: AUD 670.25
- Top region: Brisbane
